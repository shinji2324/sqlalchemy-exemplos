# Projeto Exemplo para trabalhar com SQLAlchemy

Créditos: [Canal Programador Lhama](https://www.youtube.com/@ProgramadorLhama)

Este projeto contêm exemplos de utilização da biblioteca SQLAlchemy para realizar operações ORM (_Object-relational mapping_) e trabalhos com bancos de dados SQL em Python.

O projeto está organizado na seguinte estrutura de diretórios:

 - `configs`: Contêm as configurações de conexão com o banco.
 - `entities`: Contêm as entidades, isto é, as tabelas do banco.
 - `repository`: Contêm os repositórios, isto é, as classes que irão realizar operações no banco de dados.
